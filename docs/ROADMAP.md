# Roadmap

These milestones are directional, not promises. Usage and technical discoveries may change them.

## v0.1 — Prototype / NA7 pilot — Complete

Proved reliable detection and Discord reporting of real server manifest changes.

## v0.2 — Multi-server engine — Current / Complete

Configurable monitoring of arbitrary public Reforger servers with independent state, history, confirmation, and Discord destinations, plus server lookup.

## v0.2.9 — Scale and hardening — In development

Validate Core with a representative five-server fleet across four communities on free API access (3,600 base polls/day). Add global exact-version enrichment caching and optional credentials for operators who need higher quotas. The 33-server expansion is deferred; no paid API access is required for ordinary self-hosting.

## v0.3 — Player-facing change information

Investigate what Mod Recon can reliably explain about changes: richer Workshop metadata, changelogs, authors, dependencies, historical observations, and meaningful grouped deployments where evidence supports them. AI summaries are not assumed.

## v0.4 — Hosted architecture

Operate a canonical instance across many servers with deployment, backups, health monitoring, migrations, observability, and scalable shared monitoring or subscriptions.

## v0.5 — Discord Bot MVP

Let communities invite Mod Recon instead of operating their own webhook service. The bot would be an interface to the monitoring system, not the monitoring architecture.

## v0.6 — Management dashboard

Offer Discord authentication, guild and channel selection, human-readable server search, monitoring toggles, and notification preferences without requiring ordinary admins to edit YAML or know server IDs.

## v0.7 — Community beta

Deploy with a limited number of real Reforger communities and use observed behavior and feedback to set priorities.

## v0.8 — Discovery / public utility

Explore a public server and change-history experience based on what beta users actually value.

## v0.9 — 1.0 hardening

Security, reliability, onboarding, documentation, deployment, and cleanup.

## v1.0 — Public stable release

Stable open-source core plus a hosted community service.
